## ✨ المميزات الرئيسية (Key Features)
- **رفع وتحليل البيانات الفوري:** يدعم ملفات CSV و Excel مع تنظيف ذاتي وتصحيح تلقائي للأعمدة.
- **لوحة مؤشرات تنفيذية (Executive Dashboard):** رسوم بيانية تفاعلية متقدمة لعرض الإيرادات والأداء عبر الزمن.
- **التنبؤات الذكية (AI Forecasting):** مدعوم بخوارزميات `XGBoost` لاستشراف المبيعات المستقبلية بدقة.
- **مساعد ذكي تفاعلي:** دردشة ذكية مدمجة للإجابة عن أي استفسار يتعلق بالإيرادات والمنتجات والأسواق.
- **دعم ثنائي اللغة (Bilingual):** واجهة متكاملة باللغتين الإنجليزية والعربية (مع دعم اتجاه RTL).
